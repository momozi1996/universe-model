## 2. 数据实况（results/data/manifest.json）

- 采样直接在归一化单位（G=M0=L0=1）内进行；位置/速度按 L0=1 与 Kepler 相似性 s^(-1/2) 缩放。
- **二体 400 条**（train 280 / val 60 / test 60）：e ∈ [0.0008, 0.7995]，质量比 ∈ [1.06, 99.9]，RK4 dt=0.002、输出间隔 0.01、128 帧（总时长 1.27）。截断率 **0%**（0/400）。
- **三体 800 条**（train 600 / val 100 / test 100）：质量比 ≤ **10:1**（先导收窄，v2.0 原为 100:1），最小初始间距 > 0.1，含 10% 近遇压力桶（80 条，初始最小间距 ∈ [0.05, 0.1)），负总能量束缚。截断率 **7.6%**（61/800，原因均为 min_separation < 0.02），截断帧记入 `valid_len`，训练/评测不使用截断后帧。
- 每帧存 pos/vel/**解析牛顿加速度标签**（float64 存储，模型 float32 训练）。
- 数据生成墙钟时间：**4.8 秒**（预算 < 10 min ✅）。

## 3. 模型与训练

- 结构：不变量节点标量（μ, |u|²）→ 4 层消息传递（masked mean 聚合）→ 无序对 z_ij=[h_i+h_j, |h_i−h_j|, μ_i+μ_j, μ_iμ_j, log r_ij] → s_ij=softplus(MLP) → F_ij=s_ij·d_ij/r_ij 沿连线**反向等量**分配；r_ij clamp 1e-4；padding/对角线全屏蔽。
- **参数量：464,641**（写入 checkpoints/config.json）。
- 优化：AdamW lr=3e-4、wd=1e-5、grad clip 1.0、seed=42；分阶段 S1(force, 20 ep) → S2(+state, 20 ep) → S3(+rollout 4→8 步 +0.01·L_energy, 30 ep)；全部 epoch 跑满（20/20/30），val 选最佳 checkpoint，test 只在最终评测用一次。
- **训练墙钟时间：2039.8 秒（34.0 min）**（预算 < 45 min ✅）。为保时限，S1/S2 每 epoch 随机子采样 60,000 帧（全量 107,555 帧），已记录于配置 `frames_per_epoch`。
- 训练实况（results/train.log、results/loss_curves.png、results/train_history.json）：
  - S1 best val L_force = **0.04286**；S2 best val = **0.01709**；S3 best val（8 步 rollout+force 复合）= **0.00870**。
  - 训练中观察到个别 epoch 出现单批 loss 尖峰（极端近遇帧，如 S1 ep12、S2 ep9、S3 ep8），均自动恢复，未影响 val 选择与最终模型。

### 训练稳定性坑（重要技术记录）

逐帧 RMS 归一化的 L_force 跨越约 8 个数量级（二体质量比 100:1 系统 rms²≈5e-5，三体近遇帧 rms²≈5.6e³）。朴素训练的初始批次使 force 头 softplus 被打入深度饱和（"死亡 softplus"），val 永久卡在 ≈1.0（预测全 0）。实测有效修复（SPEC 损失公式不变）：**force 头末层偏置初始化为 −2（初始 s≈0.127）+ 300 步 lr warmup**。曾尝试的有界损失变体（r/(1+r/C)、min(r,C)）均会产生 pred=0 吸引子，弃用。

### 4.4 大步长判决实验（40 条三体 test 轨迹，固定物理时长 T=0.8；真值 RK4 dt=0.001）

| 路径 | 末端相对误差中位 | p90 |
|---|---|---|
| 解析 KDK dt=0.01（80 步） | 2.33e-06 | 6.27e-02 |
| 解析 KDK dt=0.05（16 步） | **5.82e-05** | 8.34e-01 |
| 模型 dt=0.01（80 步） | 5.68e-03 | 8.71e-02 |
| 模型 dt=0.05（16 步） | **5.64e-03** | 8.61e-01 |

- **判决：模型在 dt=0.05 不优于解析力在 dt=0.05**（中位 5.64e-03 vs 5.82e-05，差约 97 倍；逐轨迹胜率 2.5%）。大步长故事在本先导版**不成立**，如实报告。
- 值得记录的观察：模型误差对 dt 几乎不敏感（0.01 与 0.05 中位误差相同量级，甚至 0.05 略低），即模型 rollout 误差由力模型本身主导而非积分误差；解析 KDK 的误差则随 dt 明显增长（2.3e-06 → 5.8e-05）。模型 dt=0.05 无超界停止（0/40），dt=0.01 有 3 条因 min_separation 停止。
- 注：SPEC 原文"16 步（物理时长 0.8）"仅在 dt=0.05 下自洽；本实验按**固定物理时长 T=0.8** 实现（dt=0.01 → 80 步，dt=0.05 → 16 步），保证公平对照。

## 5. 失败案例与已知限制

- **能量不守恒**：16 步能量漂移中位 3.2e-03，近遇样本 max 6.76。力头允许速度依赖，构造上不保证能量守恒（SPEC 本就不宣称）。
- **近遇样本**：短窗误差 max 0.488、守恒实验 2 条超界停止，全部源于近遇（截断阈值 0.02 附近）轨迹；无软化（softening）处理。
- **大步长不成立**（见 4.4 数字）。
- 长时混沌行为未验证（仅 ≤128 帧 / T≤1.27）；N>4 未训练未测试；双曲轨道教师分支有实现但未覆盖数据；二体质量比 100:1 的模型相对误差大于三体典型水平（训练中该人群收敛最慢）。
- 模型 float32、教师 float64；归一化基准一次 rollout 内固定（NormState），无逐步重缩放。
