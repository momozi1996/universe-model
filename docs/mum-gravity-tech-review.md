## 2. 三个技术硬骨头与化解方案

### 2.1 长时 rollout：物理天花板，不是工程问题

三体是混沌系统，Lyapunov 时间只有几个穿越时间量级。初值差 ε，几十圈后轨迹误差指数放大到 O(1)。**任何模型——包括完美的——都无法在长时域做点对点轨迹追踪。**

v2.0 §12.2 已有"不能因混沌忽略短时误差"的正确表述，但还需要反向的一条：**也不能因逐点轨迹发散就判定模型失败。**

**建议修改（§12 评测协议）：**
- 评测指标分两族写死：
  - **短时族**（几个穿越时间内）：逐点位置/速度误差、单帧力误差——这部分必须精确；
  - **统计族**（长时域）：逃逸时间分布、能量漂移率、角动量漂移、事件发生率（近遇/逃逸/交换）的分布匹配——这部分按分布评估，不按单条轨迹评估。
- W04 出口标准加一条："明确写出模型从逐点可信退化到仅统计可信的时间边界"。

### 2.2 近遇奇点：学习模型第一个死的地方

r→0 时力按 1/r² 爆炸，样本中力的大小跨越好几个数量级，裸 MSE 会被极少数近遇样本主导——方案 §9.1 已意识到，但工程上还需三件套：

**建议修改（§8 数据 / §9 训练）：**
- **数据侧**：近遇样本过采样（按最小距离分桶，每桶保底样本量）；近遇样本保留有效性标签的设计（§8.2）很好，保留。
- **特征侧**：`log r_ij`（§6.2 已有）之外，增加 `1/r_ij` 类特征并做截断/夹取，避免单一 log 特征在极端距离上分辨率不足。
- **模型侧**：预留软化参数 ε 的模型配置位。需要软化时按 v2.0 自己的原则处理——定义为**不同的模型配置**写入模型卡，不在同一权重里偷偷改。

### 2.3 能量漂移：评审和用户的第一攻击点

对称成对力不保证来自势能（§6.3 已诚实声明）。要预期：长 rollout 的能量漂移曲线会是最先被质疑的图。

**建议修改（§6 / §11）：**
- 在 W04 增加一个**架构消融臂**：势能头 `U_θ` + 对位置自动微分取力（HNN 式 [M03]）vs 当前的直接力头。两者在相同数据、相同更新器下对比能量漂移与短时精度。
- 这一消融本身就是可发布内容（"守恒先验在混沌 N-body 学习中的实际价值"），无论哪边赢都有结论。
- 注意方案已提醒的关键实现细节：势能路径的推理必须保留对位置的自动微分，不能走完全关闭梯度的推理路径。

## 3. 定位风险：速度故事在这个尺度上讲不通

v2.0 §3 已承认"小规模牛顿三体的解析力计算本来就很便宜"。把推论推到底：

> 一次解析 `mᵢmⱼ/r²` 比一次网络前向快几个数量级。**"模型比求解器每步更快"在 MUM-Gravity 的尺度上永远不成立。**

如果首代模型的唯一故事是"用神经网络复现牛顿力"，它会是一个"正确但没有存在理由"的模型。建议把模型价值押在两个**可判决的实验**上：

### 3.1 大步长优势实验（建议升为核心卖点）

数值积分器在近遇和精度要求下必须用小步长；学习模型可以直接学**大步长 flow map**。

- **判决性实验**：解析 Newton 力 + KDK 在 dt=0.005 需要的步数， vs 学习模型在 dt=0.05 / 0.1 下同精度的步数。若模型能用 10–20 倍大的步长保持同精度，**端到端加速的故事就成立了**——这是"学习型动力学模型有存在理由"的最强证据。
- **建议修改**：§11 配置中 `normalized_dt` 从单值改为扫描集合 `{0.005, 0.02, 0.05, 0.1}`；§12 基线表加一行"解析力 + 大步长"对照（大步长下解析基线精度会崩，这正是模型的机会窗口）。
- 时间点：从 W03 就埋入，不要等 W04——它是分水岭，决定这个项目是"复现练习"还是"有方法故事"。

### 3.2 失稳时间 / 结局预测（建议列为 0.2 版目标）

给定三体初态，直接预测"多久后失稳、哪个天体被甩出"。这是分类/回归任务，**绕开混沌逐点追踪难题**，且是已有科学价值的问题形态。

- 与 §14 版本路线对接：建议把 "MUM-Gravity-0.2" 的核心能力从"更广条件"明确改为"**更广条件 + 结局预测头**"。

## 4. 查新漏洞：Breen et al. 必须进方案

v2.0 §22 的先例清单（GNS、EGNN、HNN）漏了一个**最直接**的先例：

> **Breen, Foley, Boekholt & Portegies Zwart, "Newton vs the machine: solving the chaotic three-body problem using deep neural networks", arXiv:1910.07291, MNRAS 2020。**

深度网络预测三体结局——正是 §3.2 的任务。

影响与应对：
- **"首个学习三体的模型"这一说法已被占用**，任何文案不得出现。
- 有利面：它直接证明路线可行，其数据生成与训练方案可作为 §8 的参考实现。
- 你的差异化站得住：Breen 是单次论文实验（固定初始化家族、无开源权重产品、无交互界面）；你做的是**通用 N 体（2/3/4/8）权重 + 完整开源 + 可复现评测 + Lab 产品**。定位不冲突，但 §20 的研究定位段必须引用它并明确区分。
- **建议修改**：§22 增加 M07 = Breen et al.；§3 表格"三体"一行补充"结局预测已有直接先例（M07），本项目的增量是通用 N 体重力模型与开放评测"。

## 5. 最小验证路径（建议替换 §17 的线性排期）

v2.0 的 W01–W07 是合理的工程分解，但**缺少一个"解析裁判"阶段**。直接上三体的风险：模型错了、数据错了、还是混沌本来如此，三者无法区分。

**建议的最小验证路径：**

```
Week 1–2  二体先行（解析裁判阶段）
  - 只有二体：Kepler 问题有解析解，是绝对裁判
  - 验证全链路：归一化 → 对称力 → KDK rollout → 误差诊断
  - 出口：椭圆/双曲线轨道解析对照通过；任何 bug 一小时内可定位

Week 3–4  三体短窗 + 近遇压力测试
  - 复现一个已知周期解（如 8 字形解）作为定点检查
  - 近遇分桶误差报告；短窗 rollout（4/8/16 步）误差曲线

Week 5–6  大步长判决实验（分水岭）
  - dt 扫描 × 精度对照；得出"模型是否有存在理由"的判决
  - 通过 → 继续 W05/W06；不通过 → 收缩定位为"开源复现 + 教育资产"，诚实发布

Week 7–8  失败案例集 + 模型卡 + v0.1 权重发布
  - 失败案例与成功案例同等重要地写进模型卡
```

二体先行的价值：解析解在手，全链路任何环节出错都能立刻定位；这是整个项目**最便宜的一份保险**。
