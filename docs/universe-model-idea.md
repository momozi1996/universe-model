# 宇宙模型（Universe Model）：解决什么问题，才能被世界记住

> 日期：2026-10-13。
> 性质：一份新想法的独立构想文档，与《MOMO Universe Mode》研究方案互补——那份文档回答"怎么严谨地做"，这份文档回答"为什么要做、先解决什么问题"。
> 状态：纯构想。尚未建仓库、未写代码、未训练模型。

## 0. 一句话想法

> **世界模型（World Model）在教 AI 理解"一个环境"；宇宙模型（Universe Model）要教所有人理解"我们身处的这个宇宙"。**
>
> 把它开源到 GitHub，用一个全世界都听过的问题——三体问题——作为第一个能被亲手运行的实验，占领"宇宙模型"这个心智位置。

## 1. 为什么是现在

世界模型是当下 AI 最热的方向之一：从 Ha & Schmidhuber 2018 年的 World Models，到今天各家视频生成模型都在自称"世界模型"。它们的共同点：**学习一个环境的动力学，用于预测和推演**。

但"世界"被用得越来越小——一个游戏关卡、一段驾驶视频、一个机器人房间，都叫世界模型。

这里有一个空位：

| 模型层级 | 模拟对象 | 现状 |
|---|---|---|
| 世界模型 | 局部环境（游戏、驾驶、房间） | 极度拥挤，巨头混战 |
| 地球模型 | 气候、天气（如 GraphCast、盘古） | 已有大玩家，但垂直 |
| **宇宙模型** | **轨道、恒星、星系、宇宙演化** | **名字没人占住，心智没人占住** |

宇宙建模的科学工作其实很多（UniverseMachine、IllustrisTNG、CAMELS、AION-1……见《MOMO Universe Mode》第 3 节），但它们全部是**科研工具**——没有一个以"帮助普通人理解宇宙"为使命、以开源交互实验为形态、占住"Universe Model"这个名字的项目。

**这就是机会：不是发明宇宙模拟（早就有人做），而是发明"宇宙模型"这个品类在公众心智中的样子。**

## 2. 核心问题：宇宙模型应该解决什么人类的问题？

这是整份文档最重要的一节。我的判断是：**一个宇宙模型要活下去，必须同时回答四层问题，而且顺序不能错。**

### 2.1 问题分层模型

```
        ┌─────────────────────────────────┐
  第4层 │  哲学问题：我们在宇宙中是什么位置？   │  费米悖论、大过滤器、宇宙命运
        ├─────────────────────────────────┤
  第3层 │  科研问题：这组假设下宇宙会怎样？     │  参数实验、模拟、代理模型
        ├─────────────────────────────────┤
  第2层 │  理解问题：为什么宇宙是这样运作的？   │  教育、直觉建立、可交互的解释
        ├─────────────────────────────────┤
  第1层 │  出圈问题：一个让人忍不住点进来的问题 │  三体、洛希极限、戴森球
        └─────────────────────────────────┘
```

- **第 1 层（出圈问题）决定有没有人知道你。** 它必须是"非专业者也听过、想知道答案、且有戏剧张力"的问题。
- **第 2 层（理解问题）决定用户留下来得到什么。** 运行一次实验后，他的直觉应该被改变——"原来差 0.001 的初值，结局完全不同"。
- **第 3 层（科研问题）决定这个项目的天花板。** 当出圈入口带来关注和贡献者，才谈得上代理模型、误差验证、论文。
- **第 4 层（哲学问题）决定传播的深度。** 它不给答案，但给"必须分享"的理由。

**绝大多数科学可视化项目死在只有第 2 层；绝大多数科幻内容号死在只有第 1、4 层。宇宙模型的独特机会是四层打通：用出圈问题引流，用可运行实验建立信任，用开源积累科研能力，用哲学问题制造传播。**

### 2.2 筛选标准：什么问题配得上做"招牌"

一个候选问题要进入首发名单，需要同时过四关：

| 关卡 | 问法 | 反例 |
|---|---|---|
| **出圈度** | 不关注科学的人听说过吗？ | "暗物质晕的组装历史"——没人听过 |
| **可计算** | 能用明确方程/规则算出结果吗？ | "外星人长什么样"——纯想象 |
| **可验证** | 结果对不对能检查吗？ | "时间旅行会发生什么"——无法对照 |
| **可交互** | 用户改个参数，能看到戏剧化差异吗？ | "宇宙常数测量"——改了也没直观感受 |

## 3. 招牌问题候选池

按这四关评估，候选问题池如下（★ = 该维度的相对评级，三档）：

| 问题 | 出圈度 | 可计算 | 可验证 | 戏剧化交互 | 结论 |
|---|---|---|---|---|---|
| **三体问题** | ★★★（《三体》全球级 IP） | ★★★（牛顿方程直接可解） | ★★★（周期解、守恒量、精度收敛） | ★★★（初值差一丝，轨道天差地别） | **首发旗舰** |
| **洛希极限** | ★★★（《流浪地球》名场面） | ★★★（近似公式+潮汐分析） | ★★（近似阈值可对，破碎物理难） | ★★（"撕开一颗行星"很直观） | **首发简化版** |
| **费米悖论** | ★★★（"他们在哪"人人问过） | ★★（蒙特卡洛+德雷克框架） | ★★（可对解析极限，无标准答案） | ★★★（滑杆一拉，银河从热闹到死寂） | **首发旗舰** |
| **戴森球/云** | ★★（科幻圈热，大众一般） | ★★★（轨道+能量预算） | ★★（单采集器可解析对照） | ★★ | **首发简化版** |
| 引力弹弓 | ★★（《火星救援》《星际穿越》） | ★★★ | ★★★ | ★★ | 第二批前列 |
| 黑洞/时间变慢 | ★★★（《星际穿越》） | ★★（固定时空测地线） | ★★ | ★★★ | 第二批，先选一个被验证的模式 |
| 宜居带 | ★★ | ★★★ | ★★★ | ★ | 第二批 |
| 宇宙命运（热寂/大撕裂） | ★★ | ★★（给定宇宙学模型） | ★★ | ★★ | 远期宇宙学分支 |
| 时间旅行/虫洞 | ★★★ | ★（只有规则系统可算） | ★（只能验证规则一致性） | ★★ | 远期，定位为"逻辑实验" |

**首发组合建议：三体 + 费米（两个完整实验）＋ 洛希 + 戴森（两个简化入口）。** 理由：四者刚好覆盖"动力学混沌 / 概率推演 / 潮汐毁灭 / 工程狂想"四种完全不同的体验，且共享同一套"改假设 → 跑计算 → 看边界"的实验框架。

## 4. 为什么三体问题是最完美的第一个问题

单独展开，因为它是整个项目的"信任基石"。

### 4.1 它天然自带全部传播要素

- **全球知名度**：《三体》是少有的真正出圈的中国科幻 IP，"三体问题"这个词已经随小说和剧集进入大众词汇。
- **真实的数学深度**：一般三体问题没有解析解——这不是噱头，是 1889 年庞加莱奠定的、混沌理论的开端。用户运行的每一次"混沌三星之舞"，都是在亲手复现数学史上最重要的问题之一。
- **戏剧化到离谱**：三个质量相近的天体，初值差千分之一，几十圈后一个被甩出星系。"失之毫厘，差之千里"在别的领域是成语，在这里是可运行的动画。
- **但它同时严格可验证**：存在已知的特殊周期解（如 Chenciner–Montgomery 的 8 字形解）、角动量/能量守恒检查、积分精度收敛测试。**它出圈，但不民科——这正是"宇宙模型"要的品牌调性。**

### 4.2 一句话 Demo 设计

> **"这是三颗恒星。把第三颗的初始速度改 0.1%，看看这个'文明'还能活多久。"**

用户拖动一个滑杆 → 看到轨道从稳定到崩坏 → 看到诊断面板显示"第 N 圈发生逃逸"→ 系统告诉他：刚才你看到的是初值敏感性（混沌），不是数值误差——因为我们在同一初值下做了精度收敛对照。

**这一刻，用户同时理解了：三体问题、混沌、数值模拟的可信边界。这就是"帮助人类理解宇宙"的最小完整闭环。**

### 4.3 它能长成多大

三体实验不只是 Demo，它可以逐级升级成研究资产：

| 级别 | 内容 | 性质 |
|---|---|---|
| L1 | 点质量三体轨道 + 扰动对比 + 误差诊断 | 出圈 Demo |
| L2 | 三星系统里的行星：什么轨道能存活？辐照变化多大？ | "乱纪元"的可计算版本 |
| L3 | 不同积分器/精度/语言实现的 Benchmark | 可被引用的技术资产 |
| L4 | 用学习模型预测"这组初值何时失稳" | 第一个真正的 AI-for-宇宙 研究问题 |

L4 尤其值得注意：**"预测三体系统的失稳时间"是一个有真实科学价值、有数据、可严格评估的学习任务**——比"训练一个大模型生成星系图片"扎实得多。

## 5. 宇宙模型 ≠ 大号世界模型：定位声明

为了避免被淹没在"世界模型"的噪音里，项目需要一句清晰的切割：

> 世界模型学习的是**环境的规律**，服务于**智能体的决策**；
> 宇宙模型计算的是**物理的定律**，服务于**人的理解**。

差异落在三件事上：

1. **可解释先于可生成。** 世界模型可以是个黑箱，只要预测准；宇宙模型的每个输出必须能回答"这是哪个方程、哪组假设、什么近似算出来的"。
2. **边界先于规模。** 参数量、画面规模都不是目标；"这个结果在什么条件下成立、误差多大、哪里开始不可信"才是核心交付物。
3. **实验先于叙事。** 宇宙模型的产品形态不是"给你讲宇宙"，而是"给你一个能亲手改假设的宇宙"。

## 6. "第一个宇宙模型"：怎么占领这个位置

### 6.1 先说实话

从《MOMO Universe Mode》的检索看：宇宙学模拟、天文基础模型、宇宙研究 Agent 都有直接先例，GitHub 上甚至已有叫 universe-model 的仓库。**笼统的"全球第一个宇宙模型"没有依据，说出来会被懂行的人一眼拆穿。**

但"第一个"可以换一种有证据支撑的表述方式：

> **"第一个以'帮助人理解宇宙'为使命、以可复现交互实验为形态的开源宇宙模型项目。"**
> （The first open-source Universe Model built for human understanding — reproducible, interactive, and assumption-explicit.）

这句话里的每个限定词都是可以逐项防守的。先占住这个**心智位置**，把"无条件的第一个"留给将来有论文和结果支撑的具体贡献（比如 L4 的三体失稳预测基准）。

### 6.2 开源占领策略

| 动作 | 时机 | 目的 |
|---|---|---|
| 注册仓库 `universe-model` 相关命名（创建时检查可用性），发布概念提案 README | 现在 | 占名、占搜索、收集第一波关注 |
| 发布三体 + 费米两个可运行实验（v0.1） | 4–8 周内 | 让"宇宙模型"第一次可以被亲手运行 |
| 把每个实验做成"可嵌入网页的交互件"，鼓励二次传播 | v0.1 同期 | 让科技媒体/B 站/知乎有东西可贴 |
| 发布三体积分器 Benchmark（L3） | 之后 | 从"好玩"升级到"可引用" |
| 发布第一个学习模块（如三体失稳预测，L4）+ 模型卡 | 有验证结果后 | 第一次可以说"这是一个 AI 宇宙模型" |

**关键节奏判断：先开源概念、后开源实验、最后开源模型。** 倒过来（先憋大招）会让"宇宙模型"这个名字被别人先占；只做概念不落实验，又会变成空谈。

### 6.3 名字即叙事

推荐叙事主线（中英文各一句，可直接进 README）：

> 从三体到费米悖论：把关于宇宙的好问题，变成可以亲手运行的实验。
>
> From the three-body problem to the Fermi paradox: turning humanity's best questions about the universe into experiments you can run yourself.

## 7. 北极星指标

这个项目不该以 star 数为北极星（虽然它会来）。建议的北极星是：

> **"被完成的宇宙实验次数"——一个陌生人改了一个假设、跑完一次计算、看到了结果的解释和边界。**

衍生指标：实验被分享/嵌入的次数、复现实验的外部贡献者数、Benchmark 被引用次数。这些指标分别对应第 2 节里的第 1、2、3 层——出圈、理解、科研，全部可测量。

## 8. 科学红线（不能为了出圈越过的线）

出圈叙事和科学严谨不冲突，但必须守住几条线（详细论证见《MOMO Universe Mode》第 16.3 节）：

1. **三体**：分清"初值敏感性"和"数值误差"；不宣称模拟了小说里行星的季节与文明史。
2. **洛希极限**：点质量模型只给近似阈值；破碎画面标注"示意"，不宣称验证了电影里某个具体场景。
3. **费米悖论**：模拟的是"这组假设的后果"，不是"黑暗森林为真的概率"。
4. **戴森球**：理想球壳没有"一偏心就坠向恒星"的自动回复力，动画不得预设这个结论。
5. **一切"假如宇宙参数不同"的实验**，称为"模型内的假设实验"，不暗示真实宇宙可被修改。

这些红线不是束缚，恰恰是品牌：**一个连科幻入口都标注证据等级的宇宙模型，才值得被科学社区认真对待。**

## 9. 下一步行动清单

1. **本周**：定名、注册 GitHub 仓库，发布概念提案（第 6.3 节的叙事 + 四关筛选框架 + 首发四场景）。
2. **第 1–2 周**：三体数值基线跑通（用经过检验的求解器，如 REBOUND；精度收敛对照先行）。
3. **第 3–4 周**：费米/德雷克蒙特卡洛实验 + 成对参数对照 + 固定随机种子复现。
4. **第 5–8 周**：洛希、戴森简化入口；请有物理/天文背景的人核验假设与文案；v0.1 公开发布。
5. **之后**：评估是否进入 L3（Benchmark）与 L4（学习预测三体失稳）——那是从"开源项目"走向"研究贡献"的一步。

## 10. 一句话总结

> **世界模型教会 AI 预测世界；宇宙模型要教会人类提问宇宙。**
> **从三体问题开始——因为那是全人类已经听懂、却还没亲手算过的问题。**

| 候选 | 裁决 | 理由与必须修正的表述 |
|---|---|---|
| **戴森球/戴森云** | **延后到第 1.5 期，且必须改物理表述** | 清单里"验证刚性戴森球天然不稳定、会坠向恒星"是**错的**：理想均匀球壳内引力场为零，恒星偏离球心不产生回复力，是**中性平衡**而非"会坠落"（Wright 2020 已定向核验）。正确且更高级的爆点应该是：**"仿真证明刚性戴森球没有自动回中能力，所以戴森云才是正解"**——演示一组轨道采集器如何稳定工作。这个表述同样出圈，但站得住。 |
| 卡尔达肖夫指数 | **可作为费米 Demo 的内置模块，不单独立项** | 纯参数推演，几小时工作量；作为"戴森云/费米"的联动情景曲线（"按这个能耗增长率，多久到 II 型"）很自然。单独做成 Case 反而暴露内容单薄。 |
| 黑洞（吸积盘+透镜） | **延后到第二期** | 视觉天花板最高，但"简化 GR"的验证成本被低估了：固定 Schwarzschild 时空的测地线追踪仍需要验证光线路径与观察者设定，且必须区分黑洞阴影边界≠事件视界。第一期资源不够做"能验"的版本，贸然上会沦为 shader 美图，砸 C4 的招牌。 |
| 小行星撞击 | **延后；若做，删除"灭绝概率"** | 能量换算、冲击波/尘埃简化模型可以做，但"改大小速度看灭绝概率变化"必须改成"能量与选定经验模型下的环境效应估计，附输入范围与误差"。"灭绝概率"四个字是科学红线。 |
| 双星/食双星 | 第二期 | 本身干净可做，但第一期已有 2 个轨道类 Case，边际证明价值低。 |
| 高维空间 | 第二期，定位"数学思想实验" | 同意你的判断：不做高维物理求解。2D→3D 类比 3D→4D 的截面/投影交互其实是**纯几何程序**（可计算、可验证），比想象中好做，"高维生命行为"部分单独标注为科幻假设即可。是第二期性价比之王。 |
| 时间佯谬/祖父悖论 | 第三期 | 纯逻辑推演，但要做出差异化需要"两种明确规则下的一致性检查程序"，而不只是 LLM 聊天——否则和任何科幻问答没区别。 |
| 宜居带 | 第二期 | "科幻作者神器"定位很好（自定义恒星生成外星世界），留作 UGC 方向的种子。 |
| 虫洞、热寂、反物质 | 远期清单保留 | 分别对应"选定度规可视化""指定宇宙学模型的条件趋势""能量预算表"，均不承诺工程/终局结论。 |

### B.3 第一期最终阵容

```
王牌（完整实验，能跑能验能复现）：
  ① 三体      —— 证明 C1 数值仿真：混沌、敏感性、精度收敛
  ② 费米悖论  —— 证明 C2 参数推演：蒙特卡洛、假说对比、Agent 串联

流量入口（简化版，同样标注假设与边界）：
  ③ 洛希极限  —— 证明 C3 交互可视化：《流浪地球》名场面可计算化
  ④ 引力弹弓  —— 证明 C1 的另一面：同一引擎算"精确可利用"的轨道
```

一句话：**两个完整实验建立信任，两个流量入口带来人群。** 戴森云作为第 1.5 期的第一个候补（物理表述修正后），黑洞作为第二期的视觉旗舰。

## C. 第一期验收标准（"证明能力"的可检查定义）

| Case | 能看（Demo） | 能验（Validated） | 能传（传播点） |
|---|---|---|---|
| 三体 | 拖滑杆改初值，看轨道崩坏 | 同初态精度收敛对照；守恒量检查；逃逸/近遇事件记录；复现一个已知周期解 | "改 0.1%，文明提前毁灭 N 圈" |
| 费米 | 拉参数滑杆，看银河从热闹到死寂 | 可简化情形的解析对照；蒙特卡洛收敛；固定种子可重跑 | "你和德雷克之间只差 5 个滑杆" |
| 洛希 | 改天体密度/距离，看潮汐差曲线和示意动画 | 经典刚体/流体洛希极限公式对照；画面标注"示意" | "亲手算出《流浪地球》那根线" |
| 弹弓 | 拖入射角，看速度增量变化 | 简化情形的解析/能量守恒对照；参考系标注 | "《火星救援》的免费加速是真的" |

公共验收：每个 Case 的页面都必须有**假设声明、数据来源、误差/适用范围、可导出的实验记录**。缺任何一个，不算第一期的"证明"，只算一个动画。

## D. 排期与人力（沿用每周约 20 小时口径）

| 周 | 任务 | 出口标准 |
|---|---|---|
| 1 | 冻结三体+费米的输入输出、单位、实验记录格式 | 两份任务定义文档 |
| 2 | 三体数值基线 + 精度收敛对照 | 收敛报告 + 周期解复现 |
| 3–4 | 费米蒙特卡洛 + 假说对比 + 导出；洛希近似计算 | 两个可重跑实验 |
| 5 | 引力弹弓（复用轨道核心）；物理背景人士核验全部假设与文案 | 验证记录 |
| 6–7 | 四 Case 统一界面、假设声明组件、实验导出 | v0.1 候选 |
| 8 | 小范围用户观察（能否理解、复现、分享）；公开发布 | v0.1 + 真实使用日志 |

继续投入第二期的条件：陌生人能独立复现实验、计算基线通过核验、至少一个 Case 产生自然传播。三条缺两条，先修基础，不加新 Case。

## E. 一句话

> **第一期不追求"覆盖科幻热点"，追求"每个热点背后都有一个能验的计算"——三体证明你会算，费米证明你会推演，洛希和弹弓证明你值得被传播。**
